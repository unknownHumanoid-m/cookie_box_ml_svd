Design chosen (both .py's read env vars, .sh sets defaults near the top):

  `FIGURES_DIR`. `TRAIN_DATA_DIRS` is colon-separated (multiple dirs allowed).
- Evaluation env vars: `EVAL_DATA_DIRS`, `EVAL_MODEL_PATH`, `EVAL_OUT_DIR`,
  `EVAL_IDENTIFIER`, `EVAL_FIGURES_DIR`, `CLASSIFIER_PATH` (optional; if unset,
  zero-masking is disabled).
- All Python code has hard-coded fallbacks so nothing breaks if `.sh` isn't
  used.
